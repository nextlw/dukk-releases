# Dukk — downloads

Aqui ficam os instaladores do **Dukk** para computador. Este repositório não tem código: só as versões publicadas.

## Baixar

**[→ Última versão](https://github.com/nextlw/dukk-releases/releases/latest)**

| Sistema | Arquivo | Como instalar |
|---|---|---|
| **macOS** (Intel e Apple Silicon) | `Dukk-<versão>-macos.dmg` | Abra o `.dmg` e arraste o Dukk para *Aplicativos*. |
| **Windows** 10/11 | `Dukk-<versão>-windows-setup.exe` | Execute o instalador. |
| **Linux** (x86-64) | `Dukk-<versão>-linux-amd64.tar.gz` | Extraia e execute `./Dukk`. Requer `webkit2gtk-4.1` e `gtk3`. |

## Atualizar

Quando sai uma versão nova, o próprio Dukk avisa no topo da janela. Clique em **Baixar** e instale por cima da versão atual — suas conversas e seu login são mantidos.

## Avisos do sistema ao abrir

Os instaladores ainda não têm assinatura digital, então o sistema pode pedir uma confirmação:

- **macOS:** clique com o botão direito no Dukk → **Abrir** → **Abrir**. Só é preciso na primeira vez de cada versão.
- **Windows:** na tela do SmartScreen, **Mais informações** → **Executar assim mesmo**.

Baixe o Dukk somente por esta página ou pelo aviso dentro do próprio aplicativo.
